# scikit-fem in browser

Try it out at https://kinnala.github.io/skfem-demo

A single-page workbench that runs [scikit-fem](https://github.com/kinnala/scikit-fem)
in the browser via Pyodide: a script editor on the left, the solution on the right.

- **scikit-fem master.**  The `skfem` package is fetched from the `master` branch
  of `kinnala/scikit-fem` on GitHub when the page loads (cached by the browser).
- **Viewer.**  Plots are drawn by `viewer.js` from `skfem.visuals.web`, the same
  viewer that `basis.plot(u, 'web')` uses.  After each run the workbench plots
  every mesh in the script's namespace together with the arrays that fit one of
  its bases.  A plot the script displays itself, e.g.
  `basis.plot(u, 'web').show()`, opens in the viewer pane as well.
- **Open from GitHub.**  Load a script from any public repository: enter
  `owner/repo`, `owner/repo/folder`, `owner/repo@branch:path/file.py` or paste a
  `github.com` link.  The default is `kinnala/scikit-fem/docs/examples`.
- **Upload mesh.**  Uploaded files (or files dropped on the script pane) are
  placed in the working directory of the script, so that
  `Mesh.load('name.msh')` reads them; they are kept in the browser between
  visits.

URL parameters:

| Parameter | Meaning |
| --- | --- |
| `src` | Script to open, e.g. `?src=kinnala/scikit-fem:docs/examples/ex01.py` |
| `skfem` | scikit-fem to install: `github:owner/repo@ref` (default `github:kinnala/scikit-fem@master`) or anything `micropip` accepts, e.g. a wheel URL |
| `pyodide` | URL of the Pyodide distribution |

Listing a repository uses the GitHub REST API without login, which allows 60
requests per hour per IP address.

The first version was generated by Claude Opus 5.5 using the following prompt:

```
I’d like to have a single html page javascript FEM pre- and postprocessing app prototype with the following features:
- it runs scikit-fem via Pyodide as a solver
- there is a script editor window with highlighted Python source code for the solver that can be modified and rerun
- there is a visualization window which visualizes the mesh object in a canvas and the resulting solution by coloring the mesh. There is a dropdown menu for few example meshes that can be used (square, cube, circle, 1d, and so on) and a dropdown menu for the solution arrays (detect which are compatible with the Basis objects existing in the Python namespace)
- support canvas visualization for 1d, 2d and 3d meshes and scalar fields, preferably without javascript dependencies
```
